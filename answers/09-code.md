2. 年假累積安排

確認剩餘年假日數

3. 一般年假申請

最少提前7個工作天申請
透過內聯網系統提交申請
取得直屬上司批核

4. 緊急即日請假

於當日上午10時前致電上司
返回公司後3個工作天內補交申請

5. 年結期間特別安排

確認假期是否涉及12月15日至1月5日
如申請連續5天或以上年假，額外取得部門主管批准
