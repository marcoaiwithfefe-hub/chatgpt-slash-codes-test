Excel 樞紐分析表（Pivot Table）速查表

CHEAT SHEET · 由入門到實用技巧

01｜建立樞紐分析表

選取原始數據。

點擊「插入」→「樞紐分析表」(PivotTable)。

選擇新增工作表。

將欄位拖入對應區域。

04｜常用統計方式

右鍵點擊數值 → 值欄位設定 (Value Field Settings)。

| 功能 | 英文 | 用途 |
|---|---|---|
| 加總 | Sum | 總營業額 |
| 計數 | Count | 訂單數量 |
| 平均 | Average | 平均客單價 |
| 最大值 | Max | 最高銷售額 |
| 最小值 | Min | 最低銷售額 |
| 相異計數 | Distinct Count | 不重複客戶數 |

相異計數一般需要建立樞紐分析表時加入資料模型（支援此功能的 Excel 版本）。

05｜常用分析組合
| 想分析嘅問題 | 列 Rows | 欄 Columns | 值 Values |
|---|---|---|---|
| 每月營業額 | 月份 | — | Sum 銷售額 |
| 最暢銷產品 | 產品 | — | Sum 數量 |
| 分店業績 | 分店 | 月份 | Sum 銷售額 |
| 平均客單價 | 分店 | — | Average 訂單金額 |
| 員工表現 | 員工 | 月份 | Sum 銷售額 |
| 產品利潤 | 產品 | — | Sum 利潤 |

06｜進階功能
| 功能 | 操作 |
|---|---|
| 銷售佔比 % | Show Values As → % of Grand Total |
| 按月／季度分析 | 右鍵日期 → Group |
| 累積銷售額 | Show Values As → Running Total In |
| 按月增長率 | Show Values As → % Difference From |
| 排行榜 Top 10 | Value Filters → Top 10 |
| 一鍵互動篩選 | Insert Slicer |
| 時間軸篩選 | Insert Timeline |
| 自動生成圖表 | PivotChart |
| 查看數字背後明細 | 雙擊數值儲存格 |

07｜Windows 快捷鍵
| 快捷鍵 | 功能 |
|---|---|
| Ctrl + T | 將原始數據轉為表格 |
| Alt → N → V | 建立樞紐分析表選單 |
| Alt + F5 | 更新目前樞紐分析表 |
| Ctrl + Alt + F5 | 更新全部資料 |
| Ctrl + 1 | 設定數字格式 |

08｜常見問題

數字變咗 Count 而唔係 Sum

檢查原始數據有冇文字格式或非數字內容。

新增數據後冇更新

先將原始數據轉成 Table，再按 Refresh。

日期無法按月份分組

檢查日期係咪真正嘅日期格式，有冇空白或錯誤值。

統計結果唔準確

檢查重複數據、合併儲存格，以及原始數據有冇包含小計或總計。

已將數據轉為 Excel Table

核心口訣：

想按咩分類 → 放 Rows

想比較咩類別 → 放 Columns

想計算咩數字 → 放 Values

想睇指定範圍 → 放 Filters

掌握呢四個區域，基本上就可以應付大部分日常商業數據分析，唔需要寫任何 Excel 公式。
