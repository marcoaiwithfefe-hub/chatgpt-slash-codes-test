Excel 樞紐分析表｜一頁速查表
PivotTable Cheat Sheet · 快速分類、統計、比較及分析數據
01｜建立樞紐分析表

準備原始數據，每欄有標題，避免合併儲存格及空白列。

選取數據範圍，建議先轉換成 Excel 表格。

點選「插入」→「樞紐分析表」。

選擇「新增工作表」→「確定」。

將欄位拖放到以下四個區域。

樞紐分析表欄位

日期

產品

地區

銷售額

數量

將欄位拖曳至下方區域

篩選（Filters）

日期
限制分析範圍

欄（Columns）

地區
橫向比較分類

列（Rows）

產品
縱向排列分類

Σ 值（Values）

加總－銷售額
計算及統計數值
02｜常用分析方法
| 分析目的 | 列／欄 | 值及設定 |
|---|---|---|
| 各產品營業額 | 產品 | 銷售額：加總 |
| 訂單數量 | 產品 | 訂單編號：計數 |
| 平均消費 | 地區 | 銷售額：平均值 |
| 每月營業額 | 日期（月份） | 銷售額：加總 |
| 銷售佔比 | 產品 | 總計百分比 |
| 月度增長率 | 日期（月份） | 差異百分比 |
| 銷售排名 | 產品 | 由大至小排名 |
| 累計營業額 | 日期 | 累計總計 |

03｜實際操作示例

原始數據

| 產品 | 地區 | 銷售額 |
|---|---|---|
| 咖啡 | 中環 | $300 |
| 麵包 | 灣仔 | $200 |
| 咖啡 | 灣仔 | $500 |
| 麵包 | 中環 | $400 |

樞紐分析結果

| 產品 | 中環 | 灣仔 | 總計 |
|---|---|---|---|
| 咖啡 | 300 | 500 | 800 |
| 麵包 | 400 | 200 | 600 |
| 總計 | 700 | 700 | 1,400 |

列：產品｜欄：地區｜值：銷售額加總
04｜常用功能
| 功能 | 操作方法 |
|---|---|
| 更改計算方式 | 值欄位設定 → 加總／平均／計數 |
| 顯示百分比 | 值顯示方式 → 總計百分比 |
| 日期分組 | 右鍵日期 → 群組 → 年／季／月 |
| 排序 | 右鍵數值 → 排序 |
| 快速篩選 | 插入交叉分析篩選器（Slicer） |
| 日期篩選 | 插入時間表（Timeline） |
| 製作圖表 | 插入樞紐分析圖 |
| 查看明細 | 雙擊數值儲存格 |
| 更新數據 | 右鍵 → 重新整理 |

05｜常見問題及解決方法
| 問題 | 解決方法 |
|---|---|
| 加總變成計數 | 確認原始數據為數字格式及數值 |
| 新增數據後沒有變化 | 重新整理，並確認數據來源範圍 |
| 日期無法分組 | 檢查是否有空白或無效日期 |
| 出現空白分類 | 清理原始數據或篩除空白 |
| 百分比不正確 | 檢查總計、列總計或欄總計百分比設定 |

核心口訣：列放分類、欄放比較、值放數字、篩選放條件。

樞紐分析表不會修改原始數據，可以放心調整欄位，從不同角度分析同一份資料。
