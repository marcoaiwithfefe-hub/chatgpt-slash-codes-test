Excel 樞紐分析表（Pivot Table）

樞紐分析表係 Excel 入面一個非常實用嘅數據分析工具，可以將大量原始數據快速分類、統計、比較同整理，唔需要識寫複雜公式。

1. 實際例子

假設你有一間麵包店，以下係銷售紀錄：

| 日期 | 產品 | 分店 | 銷售額 |
|---|---|---|---|
| 1/11 | 牛角包 | 灣仔 | $1,200 |
| 1/11 | 丹麥酥 | 中環 | $800 |
| 2/11 | 牛角包 | 中環 | $1,500 |
| 2/11 | 丹麥酥 | 灣仔 | $600 |
| 3/11 | 牛角包 | 灣仔 | $900 |

2. 點樣建立樞紐分析表？

選取原始數據。

點擊「插入」（Insert）。

選擇「樞紐分析表」（PivotTable）。

選擇新增工作表。

將欄位拖放到以下四個區域。

3. 進階專業技巧
| 功能 | 實際用途 |
|---|---|
| Grouping | 按月份、季度、年份分析 |
| Slicer | 一鍵篩選分店或產品 |
| Timeline | 互動式日期篩選 |
| Show Values As | 計算佔比、增長率、累計銷售額 |
| Calculated Field | 計算毛利、利潤率 |
| GETPIVOTDATA | 自動擷取指定分析結果 |
| Power Query | 自動清洗及合併原始數據 |
| Power Pivot / DAX | 跨表分析及複雜商業指標 |
| Pivot Chart | 建立互動式視覺報表 |

4. Senior 級別嘅使用思維

初級使用者用樞紐分析表做統計，高階使用者用佢做商業決策。

原始數據 Raw Data
Power Query — 數據清洗
Power Pivot — 數據模型
Pivot Table — 多維度分析

Dashboard — 商業決策

真正專業嘅做法係建立一套可重複使用嘅分析系統，每次更新原始數據，只需要按 Refresh All，就可以更新整套報表。

唔係每個月重新做報表，而係一次建立系統，之後重複使用。
