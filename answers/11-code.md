行政摘要｜新年假政策

生效日期：2026年12月1日

公司將按員工年資調整年假待遇，並更新年假累積、申請及審批機制。

年假日數

| 服務年資 | 每年年假 |
|---|---|
| 1年至未滿3年 | 12天 |
| 3年至未滿5年 | 15天 |
| 5年或以上 | 18天 |

主要政策

年假累積： 最多5天，須於翌年3月31日前使用，逾期作廢。

一般申請： 提前最少7個工作天透過內聯網提交，由直屬上司批核。

緊急請假： 當日上午10時前致電上司，復工後3個工作天內補交申請。

年結期間（12月15日至1月5日）： 連續5天或以上年假須額外獲部門主管批准。

員工須注意： 提早規劃年假及留意剩餘年假使用期限。如有疑問，請聯絡人力資源部。
